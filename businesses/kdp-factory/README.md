# KDP Factory — Publicação Amazon KDP

## 1. Visão Geral
- **Produtos:** eBooks, devocionais temáticos, planos de leitura bíblica, livros infantis educativos e estudos sistemáticos.
- **Pipeline:** Pesquisa temática → Estruturação de sumário → Manuscrito → Revisão e checagem de fontes → Diagramação em formato EPUB/KPF → Capa de alta resolução → Validação de políticas Amazon → Publicação.
- **Governança:** Transparência conforme as políticas de IA da Amazon KDP.
