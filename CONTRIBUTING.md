# Contribuindo com o SpirandeliEmpire OS

1. Crie uma branch para sua funcionalidade ou correção: `git checkout -b feature/minha-feature`.
2. Mantenha as diretrizes da especificação mestre:
   - Limite financeiro de R$ 200/mês.
   - Fidelidade bíblica para o RISADA.exe.
   - Segurança e isolamento modular entre os negócios.
3. Teste os scripts de instalação e migração antes de submeter um Pull Request.
