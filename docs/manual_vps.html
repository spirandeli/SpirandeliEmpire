1. Escolha e Dimensionamento da VPS

Para manter o sistema estável e dentro da restrição financeira de até R$ 200/mês, utilize os parâmetros recomendados abaixo:

Recurso Mínimo Obrigatório Ideal Recomendado
Processador (vCPU) 2 vCPUs 4 vCPUs
Memória RAM 4 GB RAM + 2 GB Swap 8 GB RAM
Armazenamento 40 GB SSD / NVMe 80 GB SSD / NVMe
Sistema Operacional Ubuntu Server 24.04 LTS Ubuntu Server 24.04 LTS
Custo Médio Mensal ~R$ 40 a R$ 65/mês ~R$ 70 a R$ 110/mês (Hetzner / Contabo / OVH)
Dica Econômica: Uma VPS da Hetzner (ex: CPX21 ou CPX31) ou Contabo (Cloud VPS S/M) oferece 4 vCPUs e 8GB RAM por cerca de R$ 60 a R$ 90/mês, sobrando mais de R$ 100 de margem no seu orçamento mensal para domínios ou processamento auxiliar.

2. Apontamento de Domínio (DNS)

Antes de rodar a instalação, você precisará apontar o seu domínio ou subdomínio para o IP público da sua VPS:

  • Tipo: A
  • Nome (Host): @ (domínio raiz) ou empire (subdomínio, ex: empire.seusite.com)
  • Destino (Valor): IP_PUBLICO_DA_SUA_VPS (ex: 123.45.67.89)
  • Proxy Cloudflare: Inicialmente deixe em DNS Only (nuvem cinza) para o Caddy emitir o certificado SSL Let's Encrypt sem bloqueios.

3. Primeiro Acesso SSH à VPS

Abra o terminal do seu computador (PowerShell, Prompt de Comando ou Terminal Linux/Mac) e conecte-se:

ssh root@SEU_IP_DA_VPS

3.1 Criar Memória Swap (Se sua VPS tiver menos de 8GB RAM)

A Swap impede que o Ollama ou o build de containers cause travamento por falta de memória física:

# Criar arquivo swap de 4GB
sudo fallocate -l 4G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# Tornar permanente na inicialização
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

4. Clonagem e Instalação Automatizada

PASSO 1 Instalar o Git e utilitários básicos:

apt-get update -y && apt-get install -y git curl

PASSO 2 Clonar o repositório do SpirandeliEmpire OS:

git clone URL_DO_SEU_REPOSITORIO_GIT spirandeli-empire-os
cd spirandeli-empire-os

PASSO 3 Configurar o arquivo de variáveis (.env):

Copie o modelo de ambiente pronto e abra o editor:

cp .env.example .env
nano .env

Altere os seguintes campos essenciais dentro do arquivo .env:

  • DOMAIN=empire.seudominio.com (o domínio que você apontou)
  • ADMIN_EMAIL=seu-email@gmail.com (usado pelo SSL do Caddy e login inicial)
  • ADMIN_INITIAL_PASSWORD=UmaSenhaForte2026! (senha de acesso à dashboard)
  • DB_PASSWORD=TroquePorUmaSenhaFortePostgres
  • REDIS_PASSWORD=TroquePorUmaSenhaForteRedis

Pressione Ctrl + O e depois Enter para salvar, e Ctrl + X para sair do nano.

PASSO 4 Executar o instalador de 1 comando:

chmod +x scripts/install.sh
./scripts/install.sh
O que o instalador faz sozinho:
1. Verifica e instala o Docker e o Docker Compose plugin oficial.
2. Cria pastas seguras e ajusta permissões em storage/.
3. Constrói e inicializa os 8 containers (Caddy, Backend, Workers, Postgres, Redis, Ollama, Uptime Kuma).
4. Roda as migrações e insere o administrador e os 4 negócios iniciais.
5. Baixa o modelo qwen2.5:3b otimizado no Ollama.
6. Emite o certificado SSL HTTPS automático e valida a integridade.

5. Acessando a Dashboard

Após a conclusão do script, abra seu navegador em:

https://empire.seudominio.com
  • Email de Login: O que você colocou em ADMIN_EMAIL
  • Senha Inicial: A que você definiu em ADMIN_INITIAL_PASSWORD
  • Painel de Monitoramento (Uptime Kuma): https://empire.seudominio.com/kuma

6. Análise Estratégica: Usar o Modelo Leve do Ollama?

Uma dúvida muito comum para este projeto: "Vale a pena usar o modelo leve do Ollama localmente?"

Aspecto Modelo Leve Ollama (3B Local) Estratégia Híbrida Recomendada
Custo R$ 0,00 (100% grátis) ~R$ 0 a R$ 15/mês (dentro dos R$ 200)
Consumo de RAM Muito baixo (~1.8 GB a 2.5 GB) Mesmo consumo baixo na VPS
Triagem e Chat de Jeffrey Excelente (Rápido e direto) Ollama cuida de 100% do painel e comandos
Roteiros Bíblicos (RISADA.exe) Básico (precisa de supervisão para não encurtar) API Gemini 2.0 Flash / Flash-Lite gratuita para roteiros ricos
Livros Amazon KDP Limitado para manuscritos de 50+ páginas Processamento em lote via script com modelo maior
Veredito: Sim, use o modelo leve do Ollama para a VPS! Ele é perfeito para manter o sistema rodando liso sem consumir sua cota financeira. Para criar os roteiros profundos e manuscritos de livros, você pode usar os prompts do Jeffrey conectando a chave gratuita do Gemini Flash ou ligando uma GPU sob demanda via RunPod por R$ 1,50/hora quando for gerar 30 vídeos de uma só vez!

7. Comandos de Manutenção Diária

Verificar saúde dos serviços e consumo de RAM/Disco:

./scripts/healthcheck.sh

Fazer backup manual completo do banco e dos arquivos:

./scripts/backup.sh

Atualizar o sistema após você dar push em alterações no Git:

./scripts/update.sh

Visualizar logs do Jeffrey ou do Backend em tempo real:

docker compose logs -f jeffrey-worker
docker compose logs -f core-app
